# DayBrief 요약 프롬프트 테스트 케이스 v1

## 테스트 목적

사용자 관심 키워드를 기반으로 뉴스를 선별하고, 원문에 근거한 요약을 유효한 JSON으로 반환하는지 확인한다.

## TC-01. 관심 키워드 관련 뉴스 선별

- 입력: AI, 스타트업, 개발자 이직 키워드와 테스트 뉴스 4건
- 기대 결과: 관심 키워드와 관련된 뉴스가 우선 선정된다.
- 검증: 선정 뉴스의 주제와 `matched_keywords`가 일치하는가?

## TC-02. 관련성이 낮은 뉴스 제외

- 입력: 관심 키워드와 관련성이 낮은 지역 축제 뉴스
- 기대 결과: 관련성이 낮다면 해당 뉴스가 제외될 수 있다.
- 검증: 제외 사유가 실제 뉴스 내용과 일치하는가?

## TC-03. 요약 정확성

- 입력: 원문 요약이 포함된 뉴스 1건
- 기대 결과: 핵심 내용을 1~2문장으로 요약한다.
- 검증: 원문에 없는 사실이나 수치를 추가하지 않았는가?

## TC-04. 출처 보존

- 입력: 출처, URL, 게시 시각이 포함된 뉴스
- 기대 결과: 출력된 출처 정보가 입력 데이터와 동일하다.
- 검증: ID, URL, 출처, 게시 시각이 변경되지 않았는가?

## TC-05. 중복 뉴스 처리

- 입력: 제목과 내용이 유사한 뉴스 2건
- 기대 결과: 실질적으로 동일한 내용의 기사가 중복 선정되지 않는다.
- 검증: 중복 선정 여부와 제외 사유를 확인한다.

## TC-06. 빈 뉴스 목록

- 입력: `news: []`
- 기대 결과: 오류 없이 `results: []`를 반환한다.
- 검증: 유효한 JSON이며 불필요한 뉴스가 생성되지 않았는가?

## TC-07. 출력 형식 검증

- 입력: 정상적인 테스트 뉴스
- 기대 결과: 지정한 JSON 스키마에 맞게 반환한다.
- 검증: 필수 필드 누락, 잘못된 자료형, JSON 파싱 오류가 없는가?

## 테스트 결과 기록

각 테스트 결과를 PASS 또는 FAIL로 기록한다.

실패한 경우 입력 데이터, 실제 출력, 기대 출력, 실패 원인을 함께 기록한다.
