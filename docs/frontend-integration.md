# 프론트엔드 분석 및 백엔드 연동 인계

## 분석 근거 (2026-10-25, 작업 시작 시 HEAD 6072ec5)

- README는 비어 있었고 AGENTS.md, DESIGN.md, package.json, 웹 화면·라우터·스타일·상태 관리 코드가 없었습니다.
- `main.py`: FastAPI 0.3.0, 요약·피드백·기억 조회 및 health 엔드포인트.
- `agents/news_summary_agent.py`, `prompts/news_summary.md`: Groq 요약, 중요도 점수 검증, 키워드와 주제 선호도 입력.
- `collectors/rss_news.py`: RSS 수집은 CLI이며 뉴스 조회 HTTP API는 없습니다.
- `pipelines/daily_briefing.py`, `email_sender.py`: 구독자 JSON 기반 이메일 발송. 구독 관리/발송 HTTP API는 없습니다.
- `docs/automation_pipeline.md`, `docs/long_term_memory_design.md`, `API 서버 구축 및 테스트 결과.md`: 제품 흐름과 이전 구현 기록.
- 의존성은 Python 기반이며 프론트엔드 프레임워크는 정의돼 있지 않았습니다.

문서의 메모리 저장 설명과 0~1 점수 예시는 최신 코드와 다릅니다.
프론트엔드는 실제 코드의 Supabase 영구 저장 및 -5~5 점수 계약을 따릅니다.

## 우선순위와 구현

1. 브리핑을 읽는 핵심 화면: 수집 JSON 입력 → 실제 요약 API → 기사 목록·검색·필터·정렬·원문.
2. 관심 키워드 및 선택적 사용자 ID: 현재 API의 입력으로 사용하며 브라우저 설정임을 명시.
3. 뉴스별 피드백 → 실제 선호도/기록 조회. 사용자 ID가 없으면 설정 경로 안내.
4. API 미준비 상태에서도 확인 가능한 예시 화면을 별도 모듈로 제공. 실데이터 실패 시 예시로 대체하지 않음.

별도의 프레임워크나 운영 인프라를 추가하지 않도록 빌드 없는 HTML/CSS/JS를 사용했습니다.
백엔드 CORS 설정을 수정하지 않기 위해 프론트엔드의 로컬 개발 서버가 허용된 기존 API만 전달합니다.
백엔드 파일·의존성·워크플로우·기존 테스트는 수정하지 않았습니다.

## 남은 백엔드 작업

| 항목 | 현재 상태 | 다음 연동 |
|---|---|---|
| 실제 뉴스 자동 조회 | CLI만 제공 | 조회 API의 필터, 페이지네이션, 기사 스키마 합의 후 JSON 입력 UI 대체 |
| 구독 관리 | `subscribers.json` 수동 관리 | 신청·변경·해지 API, 동의 및 이메일 검증 정책 합의 |
| 인증 | 사용자 ID만 받으며 본인 인증 없음 | 로그인/세션 및 사용자별 접근 권한 도입 후 ID 직접 입력 대체 |
| Supabase | 연결 코드와 테이블명 사용 | `user_preferences`, `feedback_history` 실제 스키마·유니크 키·권한 및 환경 변수 확인 |
| 피드백 신뢰성 | 점수 조회/갱신과 이력 저장이 별도 요청 | 원자적 저장, 중복 방지, 취소/수정 계약 검토 |
| 운영 배포 | 로컬 개발 프록시 제공 | 동일 출처 리버스 프록시 또는 정확한 CORS 정책, 인증과 요청 제한 필요 |
| GitHub Actions | 서버 실행 단계에 Groq 키만 전달 | Supabase 환경 변수 전달 필요. 이번 프론트 작업에서는 수정하지 않음 |

위 항목은 제안하는 다음 작업이며 이번 변경으로 구현됐다고 간주하지 않습니다.
실제 배포 상태, Repository secrets, Supabase 테이블 존재 여부는 확인하지 않았습니다.

## 주요 제한

- 서버에 브리핑 목록/이력 API가 없어 화면의 요약은 탭 메모리에만 유지됩니다.
- 임의의 사용자 ID로 다른 사람의 기록을 볼 수 있는 현 백엔드 구조는 공개 서비스 인증으로 사용할 수 없습니다.
- 모든 기사 중복 방지, 진짜 본문 요약 정확도, 선호도가 AI 선정에 미치는 효과는 프론트엔드 검증 범위 밖입니다.
- 브라우저 시각 검증과 실제 AI/DB 연동은 [실행 안내](../frontend/README.md)의 수동 체크가 필요합니다.
