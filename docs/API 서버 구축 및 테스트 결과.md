## 6. Summary Agent 및 Long-term Memory 구현 현황

### ① Summary Agent

- Groq API를 이용한 뉴스 요약 Agent 구현
- 프롬프트 파일을 읽어 사용자 키워드와 뉴스 정보를 기반으로 요약 생성
- 모델 응답의 JSON 파싱 및 출력 구조 검증
- 빈 응답, 잘못된 JSON, 잘못된 응답 구조, API 키 누락에 대한 오류 처리
- 사용자별 주제 선호도를 Agent 입력에 전달하도록 연결

### ② Long-term Memory

- 사용자별 주제 선호도 점수 관리
- 좋아요 피드백은 +1, 싫어요 피드백은 -1로 반영
- 선호도 점수는 -5~5 범위로 제한
- 피드백 이력과 변경 전후 점수 기록
- 사용자별 선호도 및 피드백 이력 조회 API 구현
- 현재는 서버 메모리에 저장하며, 서버 재시작 시 데이터가 초기화됨

### ③ 추가 API

| 메서드 | 엔드포인트 | 기능 |
|---|---|---|
| POST | `/api/feedback` | 뉴스 피드백 등록 및 선호도 갱신 |
| GET | `/api/memory/{user_id}` | 사용자 선호도와 피드백 이력 조회 |

## 8. 남은 제한 사항

- 장기 기억은 현재 메모리 기반으로 저장되므로 서버 재시작 시 초기화된다.
- 실제 데이터베이스를 이용한 영구 저장은 구현하지 않았다.
- 선호도 정보 전달은 자동 테스트로 검증했으나, 실제 뉴스 선정 결과에 미치는 영향은 별도로 평가하지 않았다.
- 뉴스 수집, 이메일 발송, 서비스 배포는 본 담당 범위에 포함하지 않는다.
