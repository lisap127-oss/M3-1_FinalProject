오늘 브리핑과 피드백 현황을 한곳에서 확인해요.

오늘 읽을 뉴스를 골라 드릴게요

관심 키워드와 수집한 뉴스 파일을 넣으면, AI가 관련 기사만 골라 중요한 순서로 요약해요.

Enter 또는 쉼표로 추가 · 최대 20개

    뉴스 파일JSON · 최대 30건, 1MB
    JSON 직접 붙여넣기

    기사마다 id, title, summary, source, url, published_at 문자열이 필요해요. {"news": [...]} 형식이나 기사 배열을 받아요.

    뉴스를 요약하고 있어요

    기사 수에 따라 시간이 걸릴 수 있어요.

    묶음마다 최대 3분 정도 걸릴 수 있어요. 중단해도 서버 작업은 계속될 수 있어요.
    예시 브리핑이에요

    저장소의 테스트 기사로 만든 화면이에요. 실제 뉴스·AI 응답이 아니며 원문 링크와 피드백은 제공하지 않아요.

        AI가 선정하고 요약한 내용에는 오류가 있을 수 있어요. 중요한 정보는 기사 원문에서 확인하세요.

        관심사 설정

        브리핑에 쓰는 키워드와 피드백 연결 정보를 관리해요.

        쉼표나 줄바꿈으로 구분해요. 최대 20개, 각 100자까지 입력할 수 있어요.

        피드백 저장과 기록 조회에 필요해요. ID 없이도 브리핑은 만들 수 있어요. 로그인이나 본인 인증 기능은 아니에요.

        이 브라우저에만 저장돼요. 이메일 구독 설정에는 반영되지 않아요.

        이메일 구독

        현재 이메일 발송은 팀에서 관리하는 구독자 목록을 사용해요. 구독 신청·변경 API가 연결되면 이곳에서 설정할 수 있어요.
